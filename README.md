# Abysmal Bot

## Instalação
1. `python -m pip install -r requirements.txt`
2. Copie `.env.example` para `.env` e coloque seu token em `DISCORD_TOKEN=`.
3. `python bot.py`

## Importante
No Discord Developer Portal, ative **Message Content Intent** e **Server Members Intent**.

### Principais comandos
`/rank` `/leaderboard` `/ban` `/kick` `/timeout` `/warn` `/warnings` `/clear` `/lock` `/unlock` `/slowmode` `/nick` `/say` `/ticket_painel` `/suggest` `/setwelcome` `/ping` `/serverinfo` `/userinfo` `/avatar` `/botinfo` `/help`
